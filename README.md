# PotNext

> PotPlayer 全面改版设计 —— 现代本地视频播放器（Windows / Electron）

PotNext 是对经典播放器 PotPlayer 的一次彻底重设计：不再把成堆的按钮堆在主界面，而是把「找视频」和「看视频」拆成两个干净的画面——主页纵向浏览器逐级下钻挑片，播放画面只留内容和唤出式播控。

## 功能亮点

**主页纵向浏览器**

- 开屏即铺开：根文件夹一行 → 单击逐级展开子文件夹行 → 视频预览卡（16:9 缩略图 + 时长角标）
- 默认一行 6 张卡片，窗口变宽自动多放；单层超过 30 个走「还有 N 个」续块
- 浏览位置链记忆（localStorage），重启接着上次下钻的层级
- chip 双击播子树首条；导入文件夹不自动开播，回主页慢慢挑；打开文件直接播

**播放画面**

- 单击画面 = 隐藏全部界面（不是暂停）；双击全屏
- 鼠标移到窗口下方热区唤出玻璃胶囊播控条，2 秒不动自动隐藏
- 右缘热区唤出播放列表侧栏（主页不响应，主页本身就是列表）
- 按住 `→` = 2 倍速快进，松手还原
- 返回主页：左上角 `←` / `Esc` / 「⋯」菜单，暂停保留进度，再点续播
- `Esc` 逐层退出：设置 → 列表面板 → 全屏 → 返回主页

**其它**

- 亮 / 暗主题、多款强调色、毛玻璃质感
- 缩略图缓存、记住播放进度（断点续播）
- 安装包注册视频文件关联，卸载可保留播放列表 / 设置

## 安装

到 [Releases](../../releases) 页面下载最新的 `PotNext-Setup-x.x.x.exe`，运行安装向导即可（装到用户目录，无需管理员权限）。

> Windows SmartScreen 可能提示「未知发布者」：程序暂未购买代码签名证书，点「更多信息 → 仍要运行」即可。

## 开发

```bash
npm install
npm run dev     # 开发模式（--dev 带调试钩子）
npm run dist    # 打包 Windows 安装包 → dist/PotNext-Setup-*.exe
```

## 技术

- Electron 33，无打包器：纯原生 ES Modules，零运行时依赖
- contextIsolation + preload 白名单桥（`potnext` / `appActions`）
- 主进程负责文件扫描、缩略图生成、文件关联注册
- 设计规范见 [DESIGN.md](DESIGN.md)

## 已知限制

- 解码走 Chromium 内建能力：MP4 / WebM 最佳，MKV / TS 等容器视具体编码而定（计划引入 libmpv 后端）
- 字幕编码自动识别、循环模式 / 列表搜索等在后续版本补全
